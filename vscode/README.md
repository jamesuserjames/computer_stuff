## 🚀 Keyboard Shortcuts

Shortcut	Action
Ctrl+D	Compile → Run → Delete .out
Ctrl+S	Compile → Run → Delete → Hide terminal
Ctrl+A	Compile → Run → Delete → Clear → Hide
Ctrl+Z	Open terminal → Compile → Run → Delete
